# 🤖 Autonomous Multi-Agent RAG Engine

A production-grade Multi-Agent RAG system built with Python, LangGraph, Qdrant, FastAPI, and Docker.

## 🏛️ Architecture
- Router Agent
- Qdrant Vector Retrieval
- Document Relevance Grader
- Grounded Answer Generator
- Hallucination & Fidelity Checker

## 🚀 Tech Stack
- Python 3.11
- LangGraph & LangChain
- Qdrant Vector DB
- Groq LPU
- FastAPI & Uvicorn
